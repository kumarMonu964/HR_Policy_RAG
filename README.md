### STEPS TO OPERATE THIS REPO

1. Install uv

```
pip install uv
```

2. Create a venv

```
uv venv myvenv

```

3. Active the venv

```
myvenv\Scripts\activate
```

### STEPS FOR GIT AND GITHUB

1. Install Git
2. Make a repo on github
3. Make a .gitignore file in the project folder

## Commands
1. Add every file in the staging area

```
git add .
```

2. commit the changes to be made with a message to log

```
git commit -m "message goes here"
```

3. Push the changes to the repo

```
git push

```
